# English Bloom 2.0 連線與本機資料管理更新

本包為既有GitHub Pages網站的更新包，不是新網站的完整初始套件。

## 上傳方式
1. 備份目前GitHub檔案。
2. 將index.html、styles.css、app.js、sw.js四個檔案一起覆蓋到原儲存庫根目錄。
3. 保留原本config.js、manifest.webmanifest、demo.json及assets，不要刪除或換成空白來源。
4. 等候GitHub Pages部署完成，關閉網站後重新開啟並重新整理。若仍看到舊版，先再重新整理一次，或以無痕視窗確認新版已部署。
5. 在「顯示與操作設定」最下方看到「連線與本機資料管理」，版本應為2.0.1。
6. Apps Script、Google試算表與每日寄信程式均不需要修改或重新部署。

若你先前直接改過app.js中的倒數日期：新版會優先讀取端點targetDate，再讀config.js的targetDate，最後備援2028-12-31。請將自訂日期記到config.js，例如：

```javascript
window.APP_CONFIG = {
  endpoint: '保留原本的Apps Script /exec網址',
  refreshMinutes: 5,
  targetDate: '2028-12-31'
};
```

請使用你實際需要的日期；上例只是格式示範。網站不會猜測原本app.js內的自訂日期。

## 新增功能

|按鈕|效果|學習紀錄|
|---|---|---|
|重新連線|取消舊請求，重新讀取目前端點|保留|
|重設資料來源|移除本機記住的endpoint與教材快取，改用config.js來源；若未設定便要求貼上網址|筆記、收藏、進度與七項設定保留|
|更新網站版本|先確認網站可連線，再清理目前網站路徑的Service Worker與介面快取，重新載入|保留|
|匯出學習紀錄|下載JSON，包含筆記、收藏/進度、設定與來源，不含整份教材快取|不刪除|
|清除全部本機資料|需確認，清除本網站的來源、教材快取、設定、筆記、收藏、進度與bloom: Session資料|刪除，請先匯出|

清除確認視窗提供「取消」與「匯出學習紀錄」。本版沒有一鍵匯入JSON；下載檔案可作為可讀備份，請確認檔案已實際保存。

重設資料來源後，若換成不同端點，舊筆記仍保留在原端點名下，不會自動搬到新資料來源。若要查看舊筆記，可連回原來源。

## 建議操作順序
1. 暫時失敗：先按重新連線。
2. 懷疑手機記住舊端點：按重設資料來源。
3. 懷疑程式版本太舊：在線上時按更新網站版本。
4. 要恢復初始狀態：先匯出學習紀錄，確認下載後才清除全部本機資料。

清除操作只影響目前瀏覽器，不修改Google試算表、不取消Apps Script排程、不刪除其他裝置資料，也不會替你變更Google登入狀態。

目前的連線維護能處理舊網址、舊教材與舊版介面，不能修復Apps Script權限、失效部署網址、伺服器錯誤或網路封鎖。遇到問題仍應在無痕視窗直接開啟/exec，確認ok:true。

## 技術變更
- 增加讀取序號與AbortController。重設或切換端點時取消前次請求，晚到的舊回應不會蓋回新資料。
- 移除自己的bloom:儲存項目，沒有使用localStorage.clear或sessionStorage.clear。
- 快取版本按目前網站scope區隔；舊快取若混有其他儲存庫資源，只移除目前路徑項目。
- Service Worker取消註冊也限制為目前網站的完整scope，不取消其他GitHub Pages專案的worker。
- 暫時離線不主動更新網站快取。更新前需成功讀到網站檔案；清理後若網路立即中斷，仍可能需恢復網路重新載入。
- 介面支援繁體中文與英文，保留既有七項設定與手機閱讀版面。

## 驗收
- 先留一筆筆記並收藏一課，按重設來源後確認仍保留。
- 清除全部資料時先按取消，確認資料沒有刪除。
- 匯出JSON後檢查notes與progress欄位。
- 確認清除後，筆記與進度歸零；按重新連線後仍可從試算表取得教材。
- 開啟另一個同網域網站，確認這裡更新快取不會刪除另一站的資源。
- 實際Google權限、手機安裝版與跨來源連線需於部署後測試。
